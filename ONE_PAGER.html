Product overview
orkora.events · hello@orkora.events

Orchestrate every moment.

The event platform for organizers who run paid events. Registration, paid checkout, attendee tickets, and live operations in one system. Built for organizers who sell tickets in dollars, naira, cedi, and shillings, side by side.

Corporate conferences Industry summits Private gatherings

Event setup

  • Events with title, banner, location, timezone, public slug
  • Tiered tickets: GA, VIP, group, paid + free, sale windows, inventory
  • Agenda: tracks, sessions, speakers, per-session live stream URL
  • Media uploads to Cloudflare R2 via signed URLs with server-side size cap
  • Multi-org: one user, many organizations, isolated payments + branding

Registration + checkout

  • Public event pages at orkora.events/e/<code>, no account required
  • Free registration with instant confirmation; paid checkout via Stripe / Paystack / Flutterwave
  • Per-event provider auto-routes to the right one for the buyer's currency
  • Confirmation email, tap-to-open ticket QR, PDF receipt for paid orders
  • Idempotency on every surface so a flaky network never double-charges

On the day

  • Check-in via phone camera; validates the signed QR, prevents reuse
  • Live attendance: 60-min chart, registered vs checked-in, active sessions
  • Live updates: push announcements to every attendee viewing the event page
  • Join live CTA appears the moment a session is in window
  • PWA on every device; ticket QR works offline (service worker cache)

Payments + money

  • Multi-currency: USD, NGN, GHS, KES
  • Refunds initiated by organizer, verified by provider, reconciled by scheduled sweep
  • Per-order PDF receipt, emailed at payment + on refund
  • Audit log: refund, role change, admin action, with actor + reason + request id

Identity + access

  • Sign in by email + password, magic-link, Google, or Apple
  • Per-account exponential backoff + per-IP rate limits
  • Refresh-token rotation with replay detection (leaked token revokes the family)
  • Org roles: owner, admin, manager, scanner; platform super-admin for staff

Security posture

  • TLS, HSTS, strict CSP with per-request nonce, helmet, CSRF on refresh
  • RS256 JWT with kid-based rotation, argon2 passwords, peppered refresh-token hashes
  • Tenancy isolation enforced server-side and tested on every push
  • Continuous audit: deps + secrets + bundle leak + transport + API authz + ZAP

Partner API

  • REST under /v1; JWT or scoped API key (ork_...)
  • Verified, idempotent webhooks for Stripe / Paystack / Flutterwave

How it's used

Day zero
Set up the event
Sign up, create the org, create the event, add tiers + agenda + speakers, publish. The public page is live.
Day-of-sale
Sell tickets
Attendees land on the public page, pay in their currency. Organizer watches revenue + registrations roll up live on the dashboard.
Day-of-event
Run the room
Scanners check attendees in with their phone camera. Attendees follow the live agenda + chat in their installed PWA.
Day-after
Settle + report
Export attendees. Handle refunds. Reconciliation sweep catches missed webhooks. Archive the event.

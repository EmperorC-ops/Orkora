---

## Why this drill exists

Orkora is on Neon Launch, which includes 7 days of point-in-time-recovery
(PITR) coverage via copy-on-write branches. The drill exists to prove three
things in production:

1. We can create a branch from a past timestamp without operator error.
2. The branch contains a consistent schema and intact data at the chosen
   timestamp (not just at HEAD).
3. We have a repeatable, scripted verifier that a non-author can run.

S0 launch readiness requires backup + restore to be drilled at least once
before the public domain goes live. This drill closes that gate.

---

## Recovery posture

- **Provider:** Neon, EU-Central-1 (Frankfurt).
- **Plan:** Launch (10 GB storage, 7-day PITR window included).
- **RPO:** measured in seconds (Neon snapshots every WAL segment).
- **RTO for full restore-to-new-branch:** under 60 seconds.
- **RTO for pointing the API at the recovered branch:** add ~3 minutes
  (Render env var update + redeploy).

## What the drill proved

- **Schema is restorable.** All four forward-only migrations have stable
  checksums in the recovered branch, matching what's on `main`. The
  forward-only migration runner is the canonical truth and survives a PITR.
- **Data is intact.** All sentinel tables are populated. The five most
  recent `audit_events` show the refund-settlement code path running
  end-to-end on 2026-06-01 (verify-on-action plus a recheck the same week),
  proving the bugs from the 2026-05-30 security review (tickets allocated
  before order paid, no refund email, duplicate orders) are now exercised
  successfully in production.
- **The verifier is operator-grade.** Any team member can run
  `node apps/api/scripts/verify_pitr.mjs <url>` and get a pass/fail signal
  without prior context. Exit code 1 on any missing migration, missing
  sentinel table, or unreachable host.

---

## Why not include this in CI

The verifier needs a live Neon URL and a manually created branch. Wiring it
into CI would require a service account, a scheduled branch-create job, and
a tear-down step, which is more infrastructure than the current S0 launch
posture needs. Quarterly manual drills are the right cadence for this stage.
When we move to GA we will revisit.
